# UC 220 — Edit a filtering rule

The user wants to change how an existing rule handles incoming mail.

## Main flow

1. The user chooses a rule and the service shows its current settings.
2. The user makes changes and saves the rule.
3. The service confirms the update.

## Business rules

The user can change the rule's settings, including adding, changing, or removing individual conditions and actions. The edited rule follows the [business rules for creating a rule](uc-200-create-filtering-rule.md#business-rules).

## Alternative flows

### The edited rule is incomplete or invalid

Follow the [correction flow in UC 200](uc-200-create-filtering-rule.md#the-rule-is-incomplete-or-invalid).

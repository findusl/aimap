# UC 210 — View filtering rules

The user wants to see how a connected account sorts incoming mail.

## Main flow

1. The user opens the account's rules.
2. The service shows the rule titles in the order it checks the rules.
3. The user can select a rule to see its conditions, actions, and whether checking continues after a match.

## Alternative flows

### The account has no rules

The service indicates that the account has no saved rules.
